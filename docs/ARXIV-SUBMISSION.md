# arXiv submission grounding

Read the canonical [submission-policy map](../skills/arxivchecker/references/submission.md)
shipped inside the portable skill. It records the official arXiv sources checked
on **2026-11-03**, their implications, exceptions and remaining human decisions.
It covers authorship and consent, significant AI use, licenses, categories,
endorsement, metadata, source archives and ancillary files.

Recheck those official sources before submission. Local checking remains
separate from scientific review, author approval and arXiv acceptance.
[Validation](VALIDATION.md) records the local checks actually run.
